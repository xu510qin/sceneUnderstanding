# Experiments

Keep lightweight experiment plans and summaries here. Large logs and outputs should stay outside git.

Recommended structure:

```text
experiments/
  2026-09-12_smoke-test.md
  2026-09-17_gate-1.md
```

Each experiment note should include:

- Goal
- Command
- Config
- Dataset version
- Seed
- Result
- Interpretation
- Next action
